# 遇健我管理端

这是「遇健我」的 Vue 管理端，用于维护版本化内容快照、上传和复用素材、提交审核、查看 EdgeOne 构建状态和发起回滚。管理端默认以 SPA 方式构建，不参与公开首页的静态首屏。

`pnpm build:server` 和 Docker 构建会生成并内嵌管理页面。生产由同一个 Go 程序提供 `/`、隔离预览 `/preview` 和 `/api/*`，API 默认地址为同源 `/`。具体操作见 [部署指南](../../docs/DEPLOYMENT.md)。

## 工作区与版本

登录后通过左侧导航进入独立模块，顶部版本栏保持整站快照上下文。初始化按版本创建时间倒序分页寻找最近草稿，没有草稿时才选择最近版本；版本列表只读取摘要，选中后再读取完整快照。历史、审核及发布中的版本只读，可浏览记录和预览；有编辑权限时可从任何保存版本创建独立草稿，复制由服务端完成并保留来源关系。

顶部「保存」先校验和应用当前表单，再保存整份快照。普通编辑不需要手动执行 JSON 应用步骤。预览自动应用当前表单但不保存；JSON 导入、导出和诊断位于高级工具。临时反馈统一显示为右下角可堆叠 Toast，支持独立计时、悬停／聚焦暂停与关闭；模块、弹窗和消息动效遵守减少动态效果偏好。

创建发布／回滚任务及刷新任务后，管理端重新读取关联版本，更新状态、修订号和操作入口；成功后同时核对已加载的旧线上版本，反映服务端归档结果。同步完成前保持操作锁。版本读取失败仍保留已接受的任务，可以通过刷新任务重试同步。刷新任务不切换当前版本，也不覆盖未保存的 JSON；其他版本只更新摘要。

## 快照维护

内容工作台直接复用 `@yujian/schema` 的 canonical Schema 和语义校验规则，在编辑阶段提供以下能力：

- 输入停止 250 ms 后显示 JSON 语法、必填字段、字段类型、跨记录引用和素材类型问题，减少输入期间的重复分析和状态播报。
- 每条诊断包含 JSON Pointer 路径，并区分 Schema 问题与语义问题。
- 保存时，作品日期、封面、曲目时长／试听／署名、音乐和影像平台链接、现场双语字段、宣传位素材／焦点／时间／跳转、板块上限／更多链接及片段字段的诊断会定位到对应输入，并提供本地化无障碍说明。错误位于折叠区域时会展开所有祖先区域；切换记录不会隐藏整组表单中的错误。
- 曲目字段路径遵循完整快照中的实际记录顺序，重排、删除或重复引用曲目不会把诊断指向其他曲目。必需链接全部移除时，定位到添加链接按钮；必需宣传位引用清空时，定位到对应板块的内容选择框。
- 合法快照显示板块、作品、曲目、影像、现场、片段、素材和试听数量。
- 从本地导入不超过 2 MiB 的 `.json` 文件。
- 把当前合法快照导出为以 `releaseId` 命名的格式化 JSON 文件。

保存和导出始终重新校验当前编辑器文本，不使用尚未更新的防抖结果。本地导入只读取文件内容，不上传原文件。导出只包含已经通过校验的内容快照，不包含 API 地址、会话 Token、版本状态或发布任务。客户端校验用于提前反馈，不能替代 Go 服务端的最终契约、权限和乐观锁校验。

## 音乐工作台

载入或导入有效快照后，可以通过音乐工作台维护作品，无需手改 JSON：

1. 选择已有作品，或点击「新增作品」。填写双语标题、发行日期、作品类型、精选状态和平台链接。中文标题必填，英文可选。
2. 从当前快照选择图片／GIF 封面。新增服务端素材需先通过素材工作台「插入快照」，再重新载入作品表单后绑定。
3. 编辑曲目标题、时长、平台链接、署名和可选音频试听。同一作品内可新增、移除和上下移动曲目，至少保留一首。清空英文或取消试听会移除对应选填字段。
4. 将作品加入已有音乐板块，并使用上下移动按钮调整位置。界面会区分展示范围内与超过数量限制的条目，不自动改变板块启用状态和 `limit`。
5. 点击顶部「保存」，自动校验并应用作品表单，再保存完整草稿；校验失败保留输入，不发出保存请求。

已有作品和曲目 ID 保持稳定。当前不提供作品删除、ID 改名、跨作品迁移曲目或自动创建音乐板块。JSON 诊断保留，首页视觉预览通过独立面板打开。

音乐板块允许重复引用作品。排序以该作品的首个出现位置为准，跳过相邻相同引用，与最近的不同作品交换位置；没有可交换条目时禁用按钮。排序保留全部引用，不自动去重。

作品的 `trackIds` 也允许重复引用同一曲目。表单按引用顺序显示，编辑任意一处会同步该曲目的所有引用；移动或移除只作用于选中的引用位置。只要仍有引用，快照中的曲目记录就会保留，应用时每个曲目 ID 只写入一条记录。

## 影像工作台

载入或导入有效快照后，打开影像工作台，可以新增和编辑视频记录：

1. 选择已有视频，或新增记录。填写双语标题、正整数秒时长、精选状态和至少一个平台链接；中文标题必填，英文可选。
2. 从当前快照选择图片／GIF 海报，可选绑定视频素材。新上传素材需先插入快照，再重载影像表单后选择；清空英文或取消视频素材会删除对应选填字段。
3. 切换视频保留全部记录的临时输入。顶部保存时，整份快照通过校验才会原子替换 `videos` 并保存，其他内容和板块引用保持不变。
4. 保存新记录后，切换首页编排，将其加入已有影像板块并调整位置，再保存草稿。影像工作台不自动加入板块或改变启用状态、排序和展示上限。

已有视频 ID 保持稳定，新记录使用 `video_` 前缀与 UUID；当前不提供删除、ID 改名或记录数组排序。记录数组顺序不决定首页展示顺序。可选视频素材保留在快照中，公开站影像卡片仍通过平台外链打开，不提供内嵌播放；编辑表单也不加载视频。

重新载入或关闭未应用的影像表单需确认，取消会保留输入。JSON、其他表单应用或素材插入使基线过期时，旧表单不能覆盖当前快照；失败保留原文和表单，并显示错误路径。

## 现场工作台

载入或导入有效快照后，可新增和编辑现场记录：

1. 填写双语标题、城市和场馆，中文必填、英文可选；填写日期时间、状态和 HTTPS 详情链接，可选图片／GIF 海报。
2. 日期时间使用含明确时区的 ISO 8601 原文，例如 `2030-01-02T20:00:00+08:00` 或 `2030-01-02T12:00:00Z`。编辑器保留合法偏移量，不按本机时区转换；不接受缺少时区的时间。
3. 切换现场保留全部记录的临时输入。顶部保存先原子更新 `events`，完整校验失败保留 JSON 和表单。已有 ID 只读，新记录使用 `event_` 前缀与 UUID；不提供删除、ID 改名或记录数组排序。
4. 保存新现场后，切换首页编排，将其加入已有现场板块并设置位置和展示上限，再保存。现场工作台不自动修改首页编排。

首页与预览只显示日期严格晚于快照 `generatedAt` 且状态为「已排期」(`scheduled`) 的已编排记录，再遵守板块启用状态和展示上限。售罄 (`sold-out`)、取消 (`cancelled`) 和过去的现场仍可保存，但不展示；公开站日期继续以 UTC 呈现。修改时间或状态导致现有内部跳转目标隐藏时，应用会被拒绝，需要先明确调整对应跳转。

海报只用于已有内容契约，编辑表单不加载媒体，也不上传素材。取消海报或清空英文会删除对应选填字段。脏表单重载／关闭需确认，JSON 或其他表单变化会使旧基线过期，必须重新载入才能应用。

## 片段工作台

载入或导入有效快照后，可新增和编辑片段记录：

1. 选择当前快照中的图片／GIF 素材。新记录使用 `moment_` 前缀与 UUID，素材初始为空；表单不加载图片，也不上传素材。
2. 可选开启双语说明，开启后中文必填、英文可选。清空英文移除对应键，关闭说明移除整个 `caption`，不会保存空对象。
3. 跳转可选无目标、内部内容或外部平台链接。外链使用 HTTPS，可选自定义双语标签；切换目标类型会清理旧分支，关闭标签删除整个 `label`。
4. 内部目标必须在首页实际展示，存在但停用、超限或处于时间窗口外的目标也会被拒绝。选项用于选择已有内容，不能代替完整校验；错误区提供 `/moments/...` 路径。
5. 顶部保存先更新 `moments`，再保存整份快照。保存新记录后切换首页编排、加入片段板块并调整位置和上限，再保存。新片段尚未编排时不能成为内部跳转目标。

切换记录保留整组临时输入；已有 ID 只读，不提供记录删除、ID 改名或数组排序。重载／关闭脏表单需确认；JSON、其他表单或素材插入使基线过期时，旧表单不能覆盖当前内容。失败校验保留输入，不自动移除错误引用。

说明用于内容和辅助技术，公开站继续使用现有图片网格，不增加可见文案区；无说明时仍使用素材的双语替代文本。预览阻止外部跳转，正式公开站外链使用安全的 `target`／`rel`。

## 首页工作台

载入或导入有效快照后，打开首页工作台，可以维护宣传位和已有板块：

1. 选择、新增或删除宣传位，填写双语标题、媒体类型、主素材、移动端素材、海报、焦点和自动播放选项；可关联作品并设置内部或外部跳转。
2. 主素材和移动端素材必须匹配媒体类型；海报只接受图片／GIF。切换媒体类型保留旧引用，需重新选择匹配素材。服务端新素材仍需先插入快照，再重载首页表单。
3. 起止时间使用含明确时区的 ISO 8601 文本，例如 `2026-10-13T00:00:00Z`。界面展示状态以快照的 `generatedAt` 为基准，起点包含、终点排除；这些时间不会触发自动发布。
4. 调整已有宣传位、音乐、影像、现场、片段和音乐人板块的顺序、启用状态、引用位置和展示上限。音乐板块还可设置更多链接；不提供板块新建、删除、ID、类型或布局修改。
5. 新增宣传位后，需手动加入宣传位板块。删除宣传位同时移除全部宣传位板块中的对应引用；其他内容仍指向该宣传位时，完整校验会拒绝应用。
6. 顶部保存先原子更新 `heroSlides` 与 `homepage.sections`，再保存草稿；校验失败保留原始 JSON 和表单输入。

板块条目按每个引用位置移动或移除，允许合法重复引用，不自动去重。状态区分展示、停用、超限和时间窗口外；现场先筛选时间在 `generatedAt` 之后且状态为 `scheduled` 的记录，再应用展示上限。状态提示不代替完整契约校验。

## 首页视觉预览

导入或载入有效快照后，可打开首页预览。预览与公开站共享六类板块、页头、页脚、时间过滤和试听组件，提供桌面／手机视口及中英文切换；这些切换不修改快照或语言 URL，也不保存预览偏好。

- 预览初始关闭，仅打开时加载媒体。打开前自动校验并应用当前模块表单；无效表单会阻止打开，Toast 提示错误且保留输入，不显示旧画面。
- JSON 文字变化立即撤下旧 iframe。复用编辑器的 250 ms 防抖分析，原文与分析对应且完整有效后再展示；无效内容不会沿用旧画面。
- 默认按快照 `generatedAt` 展示，不模拟未来时间，也不代表已经保存、审核或上线。
- 视频不自动播放，保留手动播放与单实例音乐试听。切换宣传位会暂停旧视频、移除来源并重新加载以取消旧下载，相邻宣传位复用同一素材也不会沿用播放状态。更新快照或关闭预览会暂停并清空旧音视频来源，同时复位轮播。
- 外部链接在预览中禁止跳转，内部锚点可用。加载失败可重试；直接打开 `/preview` 只显示等待状态，不获取内容 API 或 fixture。
- 键盘可从预览工具栏进入 iframe 操作首页控件。首项 Shift+Tab 和末项 Tab 返回弹窗控件，Escape 可关闭预览并恢复触发按钮焦点；忙碌时不关闭。关闭、替换预览文档或卸载弹窗会清理子文档按键监听。
- 媒体按快照中的稳定地址加载。根相对素材路径只在预览副本中按 `site.canonicalUrl` 解析，不使用编辑器连接地址，不修改保存源；媒体无法访问时显示公开站的降级体验。

预览通过精确校验 Origin 与窗口来源的同源消息接收快照和语言，并重新执行 canonical 校验。Token、管理 API 地址、版本审核和发布状态不进入消息。快照不写入 URL、持久存储或公开站产物，也不上传到预览服务。

iframe 只隔离文档与样式；使用 `allow-scripts allow-same-origin` 的同源 sandbox 不是互不信任脚本的安全边界。预览只渲染已校验的结构化内容，不执行内容提供的 HTML、CSS 或脚本。

## 未保存与冲突保护

- 未保存状态同时涵盖临时表单与已经应用但尚未保存的快照。保存与预览自动应用当前表单；有临时表单时高级工具禁用，审核、发布与回滚需先保存。
- 切换作品、重载或关闭脏表单时，可以继续编辑或明确放弃临时输入；影像、现场和片段内部切换记录保留全部临时输入。导入和载入版本前也会保护未保存内容。失败的载入、导入或保存不会清空当前输入。
- JSON 编辑或素材插入使表单基线变化时，禁止旧表单覆盖当前快照。选择当前作品并确认放弃临时输入，即可从最新快照重新打开。
- 同时只编辑一个内容模块。脏表单切换模块、作品或版本时提供保存并切换、放弃并切换和继续编辑；保存失败不切换上下文。素材库独立保留上传表单，切换内容模块不清空它。
- 素材必须与字段用途匹配；移除曲目或调整首页展示导致内部目标丢失／隐藏时，应用被拒绝，并显示准确的 JSON Pointer。不会静默删除 hero、moment 或其他作品的引用。
- 保存期间锁定 JSON、表单和素材插入，防止迟到响应覆盖新内容。服务端修订冲突保留本地 JSON，需重新核对服务端版本；不会自动覆盖或重试。
- 退出登录请求进行中冻结内容编辑、版本和模块切换及新素材上传。退出成功才清理当前工作区；失败恢复操作，并保留快照、表单和已选素材。
- 会话失效立即隐藏管理界面并关闭弹窗，保留当前页面内的快照、表单、已选素材及确认重试状态。匿名恢复响应不销毁这些临时状态；旧会话迟到的 401 不撤销新会话。刷新或离开页面仍会丢失内存内容，重新登录前应导出未保存快照，素材文件需保留本地原件。
- 离开有未保存内容的页面时使用浏览器标准提示；浏览器可能要求此前存在用户交互。快照与表单不会自动写入 `localStorage`。

## 素材工作台

素材工作台把文件预检、SHA-256、签名直传、完成确认和快照插入串成一个可恢复流程。上传表单要求填写中文来源和中文替代文本；英文来源、英文替代文本、署名和许可信息可选。素材完成确认并进入 `ready` 状态后，才能插入当前 JSON 快照。

支持的文件约束如下：

| 类型 | MIME | 扩展名 | 大小上限 |
| --- | --- | --- | --- |
| 图片 | `image/webp` | `.webp` | 20 MiB |
| 动图 | `image/gif` | `.gif` | 20 MiB |
| MP3 音频 | `audio/mpeg` | `.mp3` | 100 MiB |
| WAV 音频 | `audio/wav` | `.wav` | 100 MiB |
| MP4 视频 | `video/mp4` | `.mp4` | 2 GiB |

浏览器以 4 MiB 分块计算 SHA-256，不会把整个大文件一次性读入内存。文件仍需完整经过浏览器和对象存储网络链路；编辑人员应保持页面打开，直到界面显示上传完成。

素材上传流程如下：

1. 客户端校验 MIME、扩展名、大小和必填权利字段。
2. 客户端分块计算 SHA-256，并携带管理会话 Cookie 与 CSRF Token 请求 `POST /api/v1/assets/uploads`。
3. 客户端向服务端返回的签名 URL 执行 `PUT`，只发送响应中声明的上传请求头。
4. 签名上传成功后，客户端携带管理会话 Cookie 与 CSRF Token 请求 `POST /api/v1/assets/{assetId}/complete`。
5. 服务端复核 MIME、实际大小和 SHA-256，素材进入 `ready` 状态。
6. 编辑人员补全卡片中的替代文本并插入快照，再单独保存草稿。

签名 URL 属于对象存储临时能力。管理会话 Cookie 不会发送到该 URL；客户端也不会把签名 URL 写入快照。快照只保存服务端返回的稳定 `src`。若完成确认暂时失败，界面只重试确认步骤，不会重复上传已经写入的对象。

### 素材库与插入

- 已登录用户首次打开素材库时自动读取。每页读取 50 条，按创建时间和 ID 倒序排列；「加载更多」使用服务端游标追加并按 ID 去重。
- 状态筛选由服务端执行，默认不显示已删除素材。类型和文本搜索只作用于已经加载的记录，搜索匹配素材 ID、文件名和 MIME；找不到历史素材时需要继续加载。
- 图片和 GIF 使用固定比例预览，音频和视频只显示图标及文件信息，不自动加载或播放。开发素材的 `/media/*` 地址按管理 API Origin 预览，插入时保留原始 `src`。
- 只有 `ready` 素材、非空中文替代文本和未重复的素材 ID 才能发起插入；当前快照与追加后的快照都必须通过完整 canonical 校验。插入只追加 `assets`，不会自动绑定到作品、影像或其他记录。
- 替代文本是快照字段，不保存在服务端素材库。刷新页面后复用历史素材时需重新填写；来源、署名和许可使用服务端持久化的权利信息。

### 失败恢复与连接切换

- 摘要、创建上传、直传和完成确认分别显示阶段与错误；上传期间文件和上传表单锁定。
- 直传失败后保留文件和表单，重新上传会创建新的签名上传。当前不支持断点续传、分片上传、并发多文件或字节进度显示。
- 完成确认失败后可以编辑替代文本，再点击「重试确认」。该操作只确认原素材，并把最新双语替代文本保留在对应卡片中。
- 切换 Go 服务地址会清空旧列表、游标、确认重试和卡片替代文本；旧连接的迟到结果不再更新界面，文件和上传表单仍保留。同一服务更新 Token 后可以继续重试确认。
- 切换模块时素材表单继续保留。上传期间退出登录会被阻止；未上传素材表单尝试退出时会提示返回素材库上传或明确放弃。关闭浏览器不会撤销已经发出的签名上传；文件可能已写入对象存储。

上传成功不等于内容已经发布。素材插入只更新当前编辑器文本，后续仍需保存草稿、提交审核、通过审核并完成发布流程。

## 本地运行

```bash
pnpm --filter @yujian/admin dev
```

独立 Nuxt 开发服务器的默认 API 地址为 `http://127.0.0.1:8080`，也可以通过 `ADMIN_API_BASE_URL` 覆盖；生产内嵌构建固定使用同源 `/`：

```bash
ADMIN_API_BASE_URL=https://api.yujian.me pnpm --filter @yujian/admin dev
```

本地登录仍使用 Go 服务配置的 OIDC 提供器；开发身份请求头不会由浏览器管理端伪造。会话与迁移配置参见 [服务端配置](../server/README.md#浏览器登录与会话)。

Go 开发服务的签名 URL 固定指向 `http://127.0.0.1:8080/local-upload/*`，因此本地素材闭环应让服务监听默认端口。服务端仅在显式开发模式接受 `X-Dev-Subject` 和 `X-Dev-Roles`；要用真实浏览器联调登录，应配置本地 OIDC 提供器和管理 Origin。代理还需保留签名 URL 与 `/media/*` 可达性，并正确配置 API 的 `ADMIN_ALLOWED_ORIGINS` 与预检请求。

开发服务使用临时本地存储，正常关闭会清理素材，重启后不能复用之前的开发上传。自动化测试分别覆盖 Go HTTP 上传闭环与管理端 API、状态机和快照插入逻辑，尚无把浏览器、身份认证和 Go 服务串联起来的完整管理端上传 E2E；公开站的 Playwright 测试不覆盖该流程。

## 使用流程

1. 打开管理端并通过配置的 OIDC 提供器登录；浏览器不输入或保存管理密码。
2. 从侧栏进入内容模块，通过顶部版本栏浏览历史或从任一版本创建独立草稿。
3. 根据摘要和诊断修正内容；只有完整有效的快照才能通过统一保存入口提交。
4. 保存时由服务端返回新的 `ETag` 和 revision；客户端不会覆盖本地未确认的版本。
5. 提交审核、通过或退回，所有状态转换由 Go 服务的 RBAC 再次校验。
6. 发布和回滚自动生成 `Idempotency-Key`，可重复点击而不会创建多个逻辑任务。
7. 发布任务进入构建阶段后，Go 内置 worker 自动生成静态页面、上传 Pages 并对账；关闭浏览器不影响任务。使用「刷新状态」更新界面展示。

云端部署创建结果不明时不会自动重试。仅 `admin` 角色可通过恢复 API 查询冻结目标、绑定已确认的部署，或确认云端未创建部署并结束任务；详见 [内置 Pages 发布与恢复](../server/README.md#内置-pages-发布与恢复)。恢复记录使用服务端认证得到的操作者身份。

## 安全边界

- OIDC 会话使用 `HttpOnly` Cookie；CSRF Token 只保存在当前页面内存，不写入 `localStorage`、URL 或静态产物。
- 管理 API 写操作使用会话 Cookie 与 CSRF 校验；对象存储签名 `PUT` 不携带 Cookie。
- 生产 COS 必须允许管理端 Origin 的 `PUT`、`HEAD`，并放行签名响应要求的 `Content-Type`、`X-Amz-Checksum-Sha256` 等请求头。
- 管理端不解析或执行内容提供的任意 HTML、CSS 和脚本；音乐、影像、现场、片段、宣传位和编排字段通过结构化表单编辑，首页预览只渲染 canonical 校验通过的结构化内容。
- 生产 API 应使用 HTTPS、短时 OIDC Token、CSP 和独立管理域名。
- 公开首页不依赖管理端；管理端不可用不会影响已发布静态站。

## 验证命令

```bash
pnpm --filter @yujian/admin test
pnpm --filter @yujian/admin test:coverage
pnpm --filter @yujian/admin typecheck
pnpm --filter @yujian/admin build
pnpm --filter @yujian/admin exec playwright install chromium
pnpm --filter @yujian/admin test:e2e
```

管理端 Playwright 构建并预览生产产物，使用独立端口 `49318`，覆盖桌面与手机尺寸的音乐、影像、现场与片段编辑、宣传位新增、素材绑定、编排、导出再导入、多表单冲突与未保存保护、双语、键盘操作和布局溢出检查。影像、现场和片段测试串联新增、应用、加入首页与真实预览，并检查保存冲突和忙碌锁定；现场另验证时间和状态过滤，片段另验证内部锚点、外链拦截与可选字段移除。首页预览测试还覆盖真实 iframe 握手、错误消息拒绝、内容应用、过期画面撤下、语言与视口、关闭重开、超时重试及样式隔离。

设置 `PLAYWRIGHT_ADMIN_BASE_URL` 后，Playwright 使用已经启动的管理站点，不另建 Nuxt 服务。例如先启动单个 Go 程序，再执行 `PLAYWRIGHT_ADMIN_BASE_URL=http://127.0.0.1:8080 pnpm --filter @yujian/admin test:e2e`，可以验证内嵌资源和路由。该模式仍拦截管理 API，不会修改真实内容或代替登录与云端联调。

预览媒体测试通过请求拦截提供本地 H.264 视频与 WAV 音频，使用原生播放接口，验证默认禁自动播放、同素材轮播切换，以及更新或关闭后旧媒体暂停、来源属性清空和有限资源请求完成。另用本地 HTTP 慢流服务器确认切换视频会取消旧的未完成响应，关闭预览会取消当前响应；不保留旧 DOM 引用，也不模拟媒体方法。这不证明真实云端取消、浏览器内部缓冲释放或其他浏览器行为；缓存恢复主要由单元测试覆盖。

保存场景通过浏览器请求拦截验证 API 契约、修订号、冲突与忙碌门禁，不代表真实 OIDC、Go API、对象存储或完整浏览器上传链路已验证。CI 在现有 E2E job 中运行管理端测试并独立归档报告与失败 trace。
