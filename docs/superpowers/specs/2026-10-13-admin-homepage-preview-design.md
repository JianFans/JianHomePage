# 管理端首页视觉预览设计

用户已授权独立设计、开发、验证和原子提交。阶段 A 经 PR 合并，主分支基线为 `eff4de2`；本阶段按既有路线图补齐视觉预览。

## 方案选择

直接嵌入管理页面会混用全局样式和媒体生命周期；独立预览应用需要额外构建与部署。采用管理端专用 `/preview` 页面与 iframe，在独立文档中复用公开站展示组件，沿用管理端构建和发布方式。

## 共享渲染边界

从公开站首页抽取 `HomepageView.vue`，显式接收 `snapshot`、`locale` 和播放器控制器，发出语言切换意图。解析规则、六类板块、页头和页脚只保留一份。公开站页面仍负责构建快照、语言偏好、SEO、JSON-LD 和语言提示；公开站现有播放器插件及底部 Dock 保持职责。

预览使用独立播放器控制器和同一个 AudioDock。HeroShowcase 新增默认开启的自动播放许可，预览显式关闭该许可，保留手动播放能力。有效快照替换、预览关闭和页面销毁时关闭播放器，重建展示组件以复位轮播及视频。

## 预览交互

新增可开关的预览面板，初始关闭以避免额外资源加载。提供桌面和手机尺寸、中英文切换、加载／失败及重试状态，工具按钮使用图标和无障碍名称。视口在有限容器内适配，避免管理页面横向溢出。JSON 编辑器和诊断继续保留，预览并不表示内容已保存或发布。

预览仅显示已经应用到 `editorText` 的合法快照；临时表单未应用时明确提示仍显示已应用内容。编辑器文字一旦变化，立即撤下旧画面并释放媒体；防抖分析追上当前原文且完整有效后再展示。不把最近有效快照继续标为当前结果，不每次输入重复完整分析。默认使用 `generatedAt`，不提供未来时间模拟。

## 文档与消息隔离

管理端样式移到管理首页入口，预览页面单独导入公开站样式。iframe 使用固定管理端路径、无 referrer 和限制导航的 sandbox；其用途是文档及样式隔离，不能把同源脚本视为互不信任的安全边界。

父子窗口使用带固定协议标识的 `postMessage` 握手。双方检查精确的 `origin` 与 `source`，只传内容快照和预览语言。接收端重新执行 canonical 校验；拒绝非法快照、错误来源、错误协议和无效语言。父页面只向当前 iframe 发送消息，关闭后解除监听。外部跳转在预览内禁用，内部锚点与手动试听可用。

快照不进入 URL、浏览器持久存储、服务端或公开站产物。Token、编辑连接、审核和发布状态不进入消息。直接打开预览地址显示等待状态，不加载 fixture 或自动获取内容 API。媒体仍由快照中的稳定资源地址加载；无法访问时沿用公开站降级。

## 验收

使用失败测试驱动共享渲染、消息契约与预览生命周期实现。浏览器覆盖真实 iframe 握手、字段应用、无效／分析滞后状态、未应用提示、双语、尺寸、关闭重开、自动播放禁用、消息来源与样式隔离。公开站回归覆盖静态生成、SEO、脚本预算、语言偏好和试听。

不调整 Go、Schema、数据库、身份接入或云部署。本阶段的浏览器验证不替代真实云环境联调。
