# 交互动效与异步状态设计

## 意图

补齐遇健我前后台的操作、等待、切换和结果反馈。用户授权独立设计及执行；本方案中的细节由实现者决定。沿用低饱和深色风格、Vue/CSS 与现有共享动效参数，不增加动画库或生产服务。

## 动效规则

- 控件反馈沿用 140 ms，内容切换 220 ms，分组入场 420 ms；新增加载循环统一 900 ms（旋转）与 1600 ms（低对比度骨架呼吸）。
- 只在真实 pending 状态循环，不延迟请求、不虚构百分比或强制最短等待时间。完成、失败、卸载均立即解除等待。
- 位移控制在 4～8 px，优先 opacity／transform；不动画全页尺寸，不在频繁轮询时反复摇动整个面板。
- prefers-reduced-motion 实时停掉旋转、呼吸及过渡。静态加载图形、文本、aria-busy 和错误／重试入口仍保留。

## 管理端

### 按钮

新增 AsyncButton：继承原按钮属性、样式、类型和事件，loading 时禁用并提供 aria-busy。原内容保留布局和可访问名称，只降低至透明，中心覆盖装饰性 ActivityIndicator；按钮尺寸不随状态改变。不能吞掉外部 disabled 或原生 fieldset 约束。

应用于保存、复制确认、提交／批准／退回审核、发布／回滚确认、版本刷新／分页、素材上传／确认／刷新／分页、发布状态刷新／恢复确认。各按钮只展示所属操作的加载态：保存不因读取版本或发布而转圈，批准与退回不会同时转圈。跟踪当前 UI 操作的局部标识，不改变 API 状态机。

### 页面与组件

- 会话初始化：用与工作区结构相近的 StudioLoading 占位，保留单一中文／英文状态播报，骨架装饰对辅助技术隐藏。
- 版本读取：保留当前版本与表单，已有 busy 继续锁定写入；版本上下文显示细加载指示及状态，不用空骨架覆盖旧内容。
- 素材库：首次没有任何记录时显示卡片骨架；刷新和追加保留已有卡片与替代文本输入，以 aria-busy 和按钮加载指示反馈。失败后退出骨架，恢复刷新入口，沿用现有错误通知。
- 历史：首次读取显示行骨架，刷新／分页保留列表，不因加载重新创建记录。
- 预览：在原 iframe 视口内覆盖骨架及等待文本，不把等待段落附在视口外造成跳动。握手前 iframe 不可聚焦，ready 后短淡入；错误、重试和关闭仍遵守原文档销毁与消息来源校验。
- 发布：显示按真实状态变化的指示图标与轻淡入，手动刷新按钮反馈 refreshing；后台轮询本身不循环弹 Toast，也不显示虚假进度。
- 编辑区：轻量 Vue 指令在 fieldset 挂载和记录更新时执行 220 ms 淡入，兼容工作台现有的 keyed 节点重建；连续切换取消上一段，减少动态效果变更时立即取消，卸载移除监听。无 Web Animations 支持时直接呈现。details 展开与选中态使用渐进 CSS 动效，动效本身不触发表单重建或移动焦点。

## 公开站

- FallbackImage 保持原生 img／picture 结构与固定尺寸；加载期间使用背景占位，成功后淡入，img 失败沿用内置占位图，picture 保持原有候选源行为。支持缓存命中、源变化、迟到事件与卸载，不隐藏禁用 JavaScript 时的图片。
- 音乐封面与 AudioDock 共用 ActivityIndicator，loading 时有真实等待指示及 aria-busy；播放、暂停、失败及切换曲目仍由现有单实例控制器决定。
- 延续现有轮播、滚动揭示、播放器与工具提示过渡；不保留离场媒体副本，不改变自动播放策略或运行时快照来源。

## 验证

单元测试验证按钮语义／禁用／重复点击、图片缓存与迟到事件、预览握手和资源清理、异步状态结束；浏览器通过延迟 HTTP 验证慢保存、版本读取、素材首次／刷新、预览等待和错误恢复，并量测控件尺寸和焦点。普通／减少动态效果都验证，桌面与手机都覆盖。最终运行两端测试、完整 E2E、pnpm verify 和 Go 内嵌页面浏览器检查。

## 非目标

不改布局主结构、权限、自动保存、上传协议、发布任务协议或媒体单实例规则。不添加虚假加载演示、全屏阻塞遮罩、动画开关或依赖升级。
