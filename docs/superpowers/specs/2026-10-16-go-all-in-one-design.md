# 单个 Go 程序运行管理后台和发布

## 已确认的要求

用户要求管理页面、后台 API、腾讯云操作和静态首页生成全部包含在一个 Go 二进制中。生产服务器不安装 Node.js、pnpm，不运行独立发布程序，不分别部署管理页面。开发与编译阶段可以使用前端工具。

## 方案

采用编译时打包 Vue、运行时由 Go 执行受控渲染的方案。相比用 Go 模板重写首页，它保留现有 Vue 组件及预览的一致性；相比把 Node 捆入发行包，它满足无 Node 运行依赖。Go 内使用纯 Go JavaScript 引擎执行预先编译的 Vue 服务端渲染程序；该程序没有文件、网络、系统命令或模块加载能力，内容只能作为数据传入。先验证真实组件渲染和浏览器交互，再连接发布流程。

## 编译与运行

- 编译阶段生成管理端静态文件、公开站浏览器资源、Vue 渲染程序，将这些文件通过 `go:embed` 打包。
- 管理页面和 `/preview` 由 Go HTTP 服务提供，管理 API 使用同一地址，前端不需要填写另一个 API 域名。
- 公开站浏览器资源与渲染程序复用现有 `HomepageView`、试听、语言、动画和样式。公开页面包含已审核内容及完整 HTML；访客不请求内容 API。
- Go 生成 `index.html`、`robots.txt`、`sitemap.xml` 及浏览器资源，直接通过 Pages HTTP API 上传。腾讯云 Token 只存在于 Go 服务。
- 编译缺少资源时拒绝生成正式发行包；生产缺少资源时拒绝启动，不返回演示页面。
- 继续使用现有 PostgreSQL、COS、登录会话和权限规则；本次不改写内容 Schema，也不迁移账号或数据库产品。

## 腾讯云与任务

- 保留已有审核、版本冻结、checksum、幂等键、回滚和审计语义。
- 不可变构建快照存于 PostgreSQL `publish_snapshots`；S3/COS 适配器兼容安全的历史媒体键，不要求 `assets/` 前缀，拒绝路径穿越和 `snapshots`／`snapshots/` 快照键。
- 原 `publisher_builds` 表继续保存排队、生成、提交、云端部署和最终结果。现有发布记录可读取，未结束任务升级前必须处理完。首次应用 `0009_publish_snapshots` 时，在同一事务内拒绝 `publisher_builds` 中的 `queued`、`building`、`submitting` 或 `deployed` 任务，以及 `publish_jobs` 中的 `pending` 任务；已应用迁移后的正常重启不受此检查影响。
- 发布器成为 Go 内部服务，实现原 `ports.BuildTrigger`，不再需要共享口令、发布网关域名或第二个进程。
- Pages 使用官方 SDK 对应的公开 HTTP 协议：验证直接上传项目、取得临时上传凭据、上传 ZIP、创建 Production 部署、查询部署。创建部署不自动重试。
- 上传开始前持久化 `submitting`。结果未知时保留记录，管理员核实后绑定部署或确认没有部署；不得自动重复创建。
- 项目、地域、公开 URL、完整运行二进制的 SHA-256 保存在任务中，重启配置或更换程序不能改变已有任务目标；恢复未完成的旧任务需要原二进制。
- 数据库锁覆盖生成和上传；丢失连接后拒绝后续状态写入，已开始的云请求保持结果未知。

## 安全与限制

- 渲染器仅执行发行包自带程序，不执行内容中的脚本。每次渲染隔离引擎，限制快照大小、运行时间、输出大小和递归深度。
- HTML 和 JSON 正确转义，内容中的 `</script>` 不能结束内嵌数据块。
- 页面资源路径必须在发行包内，API 404 不回退到管理页面，HTML 不长期缓存，带哈希文件可以长期缓存。
- PostgreSQL 快照逐字节核对 SHA-256 与 releaseId，禁止示例媒体发布，发布失败保留旧网站。
- 生产镜像和下载发行包只含 Go 程序及系统所需证书；不包含 Node、源码树和 `node_modules`。

## 验收

清空 PATH、禁止启动子进程后，单个已编译二进制能提供管理页面，生成真实内容的完整首页，完成本地模拟的腾讯云上传和部署查询。真实浏览器验证页面、预览、语言、轮播、试听；Go 单测、数据库集成、race、覆盖率和既有前端门禁继续通过。真实云账号联调单独报告，不把模拟接口通过当作上线成功。
