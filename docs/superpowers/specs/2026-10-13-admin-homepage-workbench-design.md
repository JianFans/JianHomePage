# 宣传位与首页编排设计

用户授权代理独立决定并推进下一阶段，采用 [阶段 A 规划](../plans/2026-10-13-homepage-authoring-roadmap.md)。本规格只覆盖首页编辑，视觉预览另行实施。

## 范围与交互

在管理端音乐工作台前增加可打开／关闭的首页工作台。编辑人员打开当前快照副本后，可选择、新增或删除宣传位，维护双语标题、媒体类型与素材、移动端素材、海报、焦点、自动播放、关联作品、跳转及起止时间。时间输入使用明确标注的 UTC ISO 8601 文本，避免隐式依赖本机时区；非法输入由 canonical 校验反馈。

同一草稿内维护已有六类板块的顺序、启用状态、引用位置与展示上限，音乐板块还可编辑更多链接。不创建或删除板块，不修改板块 ID、类型或布局变体。引用列表按位置操作，保留重复内容引用。新增宣传位先进入记录列表，再由编辑人员加入宣传位板块；删除记录同时移除其宣传位板块引用，整体应用必须满足最少引用等约束。

页面采用已有低饱和深色、双语字段和图标工具按钮。宣传位表单与编排列表拆成组件；窄屏单列。点击删除只修改临时草稿，可关闭并放弃，应用后仍需手动保存。

## 数据与契约

`HomepageDraft` 包含 `heroSlides` 与 `sections`，类型直接使用生成契约。`createHomepageDraft` 从有效快照深复制；`applyHomepageDraft` 比较文本基线、验证已有板块身份与布局不可变、生成替换副本并完整诊断，任何失败返回原文。板块身份按 `(ID, type, layoutVariant)` 多重集合比较，保留 canonical 允许的重复板块 ID 和每种身份的数量。只更新 `heroSlides` 与 `homepage.sections`，其他字段保持一致。

素材选项遵循校验器当前规则：主素材和移动端素材与 `mediaKind` 相同，海报只允许图片／GIF。切换媒体类型不偷偷清除已有引用；不匹配时要求重新选择。外链沿用平台链接的字段规则，但目标和更多链接只绑定单个稳定对象，不把数组编辑组件的临时包装数组当成保存源。内部目标从已有内容选取并显示可见性提示，曲目目标跟随所属作品的展示状态，最终完整语义校验保证目标真实可达。

展示状态以 `generatedAt` 为参照：停用优先；宣传位按起止窗口过滤；现场先筛选 scheduled 且未来的记录，再应用 limit；其他列表按引用位置限量。状态分为展示、停用、超限和时间窗口外。合法重复引用独立占用展示位置。未应用草稿可有无效字段，状态显示不替代完整校验。

## 状态保护

首页草稿独立持有基线、初始序列化文本、错误和待确认关闭／重载意图。打开、应用直接分析最新 JSON，列表与诊断复用防抖结果。JSON 暂时无效时，组件仅为保留字段和选项缓存最近有效快照，不将缓存用于应用校验。重载或关闭脏草稿前使用内联确认，失败保留草稿。

页面合并音乐与首页草稿的 dirty 状态；任一表单未应用时禁止保存、导出、审核、发布和回滚。两个工作台可以保留各自输入；一个应用改变 JSON 后另一个过期，不能覆盖。素材插入与 JSON 编辑也使旧表单过期。载入／导入确认成功后清理两个草稿，失败保留。保存锁涵盖所有字段和操作，成功后只刷新干净表单基线。

## 验证与边界

先写事务、状态与页面失败测试，再实现；组件验证字段绑定、重复引用位置、双语、禁用与时间提示。浏览器验证宣传位新增与编排、导出再导入、过期和替换保护、手机与键盘操作；既有音乐流程不得回归。

不修改 Schema、Go API、公开站、发布调度或云环境。公开站仍在构建时消费快照；时间窗口不触发自动重新发布。预览继续是 JSON，界面与文档明确区分。未发布快照不持久化到浏览器或公开服务。
