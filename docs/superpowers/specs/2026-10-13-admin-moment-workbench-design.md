# 管理端片段工作台设计

## 目标与决策

现场工作台已合并。下一处断点是片段仍需手改 JSON；本轮补齐记录维护、首页引用和真实预览闭环。用户要求独立完成，设计与实现由代理自检及独立审查，不等待逐项确认。

选择独立集合草稿工作台：与影像、现场保持一致，切换记录保留整组输入。把片段字段塞进首页编排会混合记录与引用职责；通用化全部工作台会扩大本轮范围，均不采用。

## 内容契约

- 只编辑 `moments`，不修改 canonical Schema、Go API、公开站布局或展示规则。
- 片段必填 `id`、`assetId`；素材仅允许当前快照的图片／GIF。新 ID 为 `moment_` 加 UUID，素材初始为空，不编造有效内容。
- `caption` 可选，通过显式开关添加或删除。开启时中文必填、英文可选；清空英文删除键，关闭删除整个字段。
- `target` 可选，允许无目标、内部内容、外部平台链接。切换类型建立对应结构并清理另一分支；外链维护 provider、HTTPS URL、可选双语标签。关闭自定义标签删除整个 label。
- 内部选项包含全部已有内容和片段草稿；存在但未实际渲染的目标仍由完整 canonical 校验拒绝。新片段可直接指向已有的可见目标；新片段本身须先应用并进入首页编排，才能被内部跳转引用。不自动添加引用或提高展示上限。
- 已有 ID 不可修改或删除；本轮不提供记录删除、重命名和数组排序。首页引用位置由首页工作台管理。

## 草稿与交接

纯事务深复制片段，应用时同步分析当前 JSON，检查精确原文基线与已有 ID，再只替换 `moments` 并执行完整 canonical 校验。失败返回原文、稳定错误代码和 JSON Pointer，保留输入。

状态机维护草稿、dirty、stale、错误与重载／关闭确认。读取失败保留原草稿和待确认意图；忙碌时拒绝操作。成功应用刷新基线，不自动保存、审核或发布。

页面将片段纳入第五个工作台：统一未应用门禁、离开保护、全局替换确认。替换成功才清理所有表单，失败保留；保存成功刷新已打开的干净表单，409 保留输入。预览只读取已应用 JSON。

## 界面与验证

复用管理端低饱和深色样式、图标工具和双语文案。列表按说明或 ID 显示；选中编辑区按 ID 隔离。素材只显示选项，不自动加载媒体；JSON 暂时无效时保留最近有效选项。诊断最多展示 8 条并本地化剩余数量。

事务、状态机、真实组件与页面按 TDD 验证。Playwright 覆盖桌面／手机新增、首页引用、真实 iframe、目标安全、可选字段移除、五表单保护、保存冲突与锁定、双语键盘及溢出。保存 API 使用拦截，仅证明契约，不替代真实云联调。运行完整前端门禁与覆盖率，独立规格／质量审查后原子提交。

OpenDesign Cloud 连接返回关闭；本轮采用已有组件视觉语言并进行真实浏览器验收。保持当前检出目录，使用专用功能分支；不推送、创建 PR、合并或部署。
