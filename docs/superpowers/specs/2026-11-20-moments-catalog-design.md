# 片段全量目录设计

## 意图

公开站的音乐、影像和现场信息均可从首页进入完整目录。片段目前只在首页显示精选项，访客无法浏览快照中的其余片段。本设计为全部片段提供稳定、可索引的静态页面。

## 目标

- 新增 `/moments/`，展示快照中的全部片段，不受首页板块启用状态和数量上限影响。
- 按快照 `moments` 数组顺序展示，尊重内容编辑者确定的顺序。
- 显示素材替代文本及可选的中英文说明。
- 保留片段现有的内部内容目标与外部链接行为。
- 页面与首页使用相同的双语、导航、页脚、深色视觉和响应式样式。
- Nuxt 静态生成与 Go 内嵌发布都输出完整目录，canonical、sitemap 和静态产物校验同步覆盖该页面。

## 范围

### 页面内容与交互

- 页面读取当前发布快照中的全部 `moments`，不按首页 `itemIds`、`enabled` 或 `limit` 过滤。
- 目录保持快照顺序。快照没有片段时显示中英文空状态。
- 图片使用现有 `FallbackImage`，卡片始终预留稳定宽高比；资源元数据中的宽高可用于尺寸提示，但不能假设每项素材都提供宽高。
- 有外部目标时打开新标签页，并设置 `rel="noopener noreferrer"`。
- 有内部目标时按目标内容类型链接到对应目录锚点：发行和曲目使用 `/music/#<id>`，影像使用 `/video/#<id>`，现场使用 `/events/#<id>`，片段使用 `/moments/#<id>`。对应目录必须为每项内容提供与内容 ID 一致的稳定锚点；不得依赖首页精选状态或编排。
- 无跳转目标时展示不可点击的图片与说明。
- 不增加灯箱、筛选、分页、详情路由或客户端内容 API。

### 导航与元数据

- 首页片段板块提供图标式“查看全部”入口。
- 目录页在站点导航中标记为当前页面，并保留现有页面入口。
- 页面提供双语标题、描述、canonical、Open Graph 标题与描述。
- Sitemap 与 Go 导出产物包含 `/moments/`。

### 实现边界

- 使用当前 Vue / Nuxt 组件、现有本地化工具和共享素材组件。
- Go 发布继续通过内嵌 Goja Vue SSR 生成页面，不引入 Node.js 服务或运行时内容请求。
- `moments` 数组顺序是唯一排序依据，不派生时间或以 ID 排序。
- 不改变快照 Schema，也不修改生成文件。

## 验收条件

- 片段数量超过首页精选上限时，目录仍显示所有记录。
- 首页片段板块停用时，目录仍可直接访问并显示全部记录。
- 中英文标题、空状态、说明、素材替代文本和导航状态正确。
- 外部目标具有安全的标签页属性，内部目标按内容类型指向实际存在的目录锚点，无目标记录不可误点。
- Nuxt 静态生成与 Go 生成都产出 `moments/index.html`，其 canonical 正确。
- Sitemap 与静态产物校验要求该页面存在，并检查本地资源引用。
- 桌面与窄屏布局保持图像比例、内容可读和键盘可访问。

## 非目标

- 修改后台片段编辑、素材上传或快照结构。
- 增加服务端动态接口、登录或用户互动功能。
- 发布、回滚或 EdgeOne 凭据配置调整。
