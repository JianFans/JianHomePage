# CMS 内容管理补齐设计

## 范围

本轮只实现站点资料可视化设置、内容删除与引用处理、统一素材选择和版本差异对比。沿用 Vue 管理端、canonical 快照、统一保存、审核发布与 Go 单程序；不增加公开站二级页面、定时发布、论坛或访客登录。

用户已要求独立完成规划、实现和核查。本设计中的交互细节由实现者确定，按以下保守规则执行。

## 站点资料

新增「站点资料」模块，维护品牌、艺人名称、canonical URL、SEO 标题与描述、分享图、艺人简介、肖像、站点社交链接和艺人平台链接。复用双语字段和平台链接字段。语言集合和未来子站导航保持现有契约，不增加新能力。

设置属于当前内容版本，参与顶部保存、预览、未保存保护、权限和历史只读。JSON 基线过期或完整快照校验失败时保留输入，不部分写入。

## 内容删除

支持从当前草稿删除作品、曲目、影像、现场、片段和宣传位。删除是快照修改，不删除历史版本或对象存储文件。作品删除同时删除所属曲目；首页编排中对应引用在明确确认后一起移除。内部跳转、宣传位关联作品等其他引用列出路径并阻止删除，用户应先修改引用，不能静默清空跳转或级联删除其他内容。

删除前显示目标和影响；有未保存表单时要求先保存，确认期间目标或快照变化使确认失效。事务执行时重新校验，失败保留原文。最后一首曲目不能单独删除。

## 素材选择

为封面、海报、试听、宣传位媒体、片段、肖像和分享图复用同一选择入口。保留原生字段与错误路径，增加图文选择与搜索，按允许素材类型过滤；可选字段可清空。

选择器可浏览当前快照与服务端分页素材库，并复用现有上传和确认能力。仅 ready、metadata 完整且通过 canonical 校验的素材可以绑定；替代文本必填。选择服务端素材时将其加入当前快照并绑定字段，保持同模块其他未保存输入。仅允许对「素材追加」重建表单基线，其他快照变化仍视为过期。退出会话、关闭选择器或迟到响应不得修改新上下文。

素材选择不执行对象删除，不实现批量、分片或断点续传。

## 版本对比

版本历史提供只读对比入口，比较两个服务端已保存版本。显示版本名称、修订、按内容类别归组的新增／删除／修改、字段路径及前后值。记录数组按稳定 ID 对齐，忽略对象属性顺序，保留条目顺序变化；避免把一次排序显示为所有记录修改。

读取使用独立状态及取消／序号保护，失败可重试。对比不切换当前版本，不修改编辑器、表单、发布任务或 URL；支持分页加载更多版本。大字段与长列表采用可展开呈现，不将 HTML 字符串注入页面。

## 验证

各事务先写失败测试再实现；组件测试覆盖权限、失效基线、引用阻止、素材类型与未保存输入、对比并发。桌面与手机 E2E 验证设置保存、删除确认、素材选择和只读对比。最终运行 lint、类型检查、单测、覆盖率、管理端 E2E，并独立审查整个功能分支。
