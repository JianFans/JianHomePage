# 用户资料与全站动效

## 目标

管理端左下角展示身份服务的显示名称和头像；在现有深色布局上完善前后台动画，不改变内容、审核和发布逻辑。沿用用户此前授权的独立实现、验证与原子提交方式。

## 用户资料

现有组件支持头像和名称，但只读取 ID token。登录授权继续请求 `openid profile email`；在完成签名、issuer、audience、nonce 等检查后，使用 token endpoint 返回的 access token 查询同一份 discovery 公布的 UserInfo endpoint。

- UserInfo 的 `sub` 必须与已验证 ID token 完全一致，仅更新名称、头像，不读取权限或替换身份。
- 支持标准 `name`／`picture` 与 Casdoor `displayName`／`avatar`，显示名称优先于登录名。
- 只接受安全 HTTP(S) 地址，生产要求 HTTPS；携带 access token 的请求禁止重定向，限制超时和响应大小。
- 资料不可用时保留 ID token 中的资料并记录固定诊断原因，不阻断已验证登录。access token 仅用于本次服务端请求，不持久化、不发送给浏览器、不写日志。
- 旧会话资料保留到重新登录；不引入后台周期性查询或额外管理 API。缺失、失败头像保留固定占位，名称最后才回退用户 ID；收起侧栏也显示头像。

## 动效

沿用 Vue Transition 和 CSS，不添加依赖。由实现者选择统一的三档时长：快速反馈 140 ms、常规过渡 220 ms、内容入场 420 ms；使用自然减速曲线。

- 首页：首屏文案轻入场，轮播媒体和标题切换轻淡入，音乐、影像、现场、片段和艺人板块进入视口时轻微上移；卡片、外链和播放控件具有一致的悬停、聚焦、按压反馈。
- 后台：登录入场、导航收展、模块切换、版本与列表反馈、表单聚焦、弹窗和 Toast 使用同一节奏；保留现有焦点管理、自动关闭和媒体释放行为。
- 滚动入场采用 CSS view timeline 渐进增强。不支持的浏览器直接展示完整内容；不使用先隐藏内容、等待 JavaScript 解锁的方案。
- 非必要动画只在 `prefers-reduced-motion: no-preference` 下运行；动态切换偏好立即生效。移动端不依赖 hover，不添加持续漂浮、视差、闪烁和循环装饰。
- 主要动画只作用于 opacity 和 transform，布局收展单独保持短过渡；不覆盖焦点轮廓，不为效果延迟内容操作。

## 验收

Go 测试覆盖真实签名登录及 UserInfo 的同身份资料、身份不匹配、网络失败、重定向、非法 URL、响应边界与权限隔离。前端单元测试和真实浏览器验证名称、头像及收起导航。桌面和手机浏览器验证正常动效、减少动态效果、轮播和播放交互、弹窗焦点、Toast 和页面无横向溢出。实际身份服务需重新登录后核实，自动化不能证明真实账号配置。
