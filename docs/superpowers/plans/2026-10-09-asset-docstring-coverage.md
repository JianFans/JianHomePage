# 素材工作台函数文档补全计划

**目标：** 为本分支触及的函数补齐有意义的文档注释，修复 Docstring Coverage 预检告警。

**范围：** `apps/admin/utils/asset-workbench.ts` 与 `apps/server` 中本分支触及的入口、素材服务、HTTP、本地存储、内存及 PostgreSQL 仓储和对应测试。仅修改注释，不改变签名、控制流或数据契约。

**执行方式：** 在当前已授权分支逐项执行，不创建工作树，不推送或部署。纯文档改动不新增行为测试。

## 执行与验证

- [x] 用 TypeScript 语法树和 Go AST 对照分支及当前改动，列出触及函数及缺失注释；远端预检的统计口径以其重跑结果为准。
- [x] 补充生产函数的职责与关键边界：权限、分页、游标、并发、冻结地址、幂等写入、上传期限和关闭清理。
- [x] 补充测试及辅助函数注释，说明所验证的行为、隔离方式和同步信号；已有准确注释保持不变。
- [x] 检查实现 diff 仅含注释，运行 `pnpm lint`、`pnpm --filter @yujian/admin test` 和 `pnpm verify:go`；数据库集成与 race 的跳过不得写成通过。

## 验证结果

- 本地语法树统计：分支触及的 91 个 Go 函数和 46 个 TypeScript/Vue 命名函数均有文档注释。该统计包含测试函数，与 CodeRabbit 的分析及跳过规则不同，不作为远端覆盖率结果。
- 比较本次修改前后的词法 token：16 个 Go 文件和 1 个 TypeScript 文件实现保持一致；Go 测试辅助方法仅因插入独立文档注释而调整空白。
- `pnpm lint` 退出码 0；管理端 12 个测试文件、80 项测试通过；`pnpm verify:go` 的格式、生成、全包测试与 vet 通过。
- 本轮未配置测试数据库，也未执行 race detector 或云集成。纯注释改动不重新执行真实数据库或发布冒烟。
- CodeRabbit 的 Docstring Coverage 必须在提交推送后由远端重新计算；本地命名函数统计不等于该预检已通过。
