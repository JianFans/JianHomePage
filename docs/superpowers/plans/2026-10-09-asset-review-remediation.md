# 素材工作台审查修复计划

> 使用 executing-plans 在当前已授权分支内逐项执行；每项先运行失败行为测试，再实现、验证并独立提交。

**目标：** 修复本次审查的六项问题，保留提供商边界、旧实例滚动升级和旧二进制回滚能力。

**架构：** 本地 BlobStore 在验证签名及声明后设置有界上传读写期限；管理端预览单独解析相对 URL；素材服务使用仅补全地址的原子仓储方法；分页索引通过新迁移添加。

**技术栈：** Vue、Vitest、Go net/http、PostgreSQL。

## 执行顺序

- [x] 1. 本地上传期限：真实 HTTP Server 和日志中间件下，延迟请求体可超过普通 API 的短期限，合法上传返回 204，普通请求仍超时。预检通过后设置 15 分钟读写期限，日志包装提供 Unwrap。目标包测试通过，提交 `8b9444a`。
- [x] 2. 相对地址预览：`/media/` 按管理 API Origin 显示，绝对媒体 URL 和插入快照的原始 src 保持不变。组件回归测试与管理端 typecheck 通过，提交 `da3b4c7`。
- [x] 3. 筛选并发：完成素材按 ID 合并进在途列表，pending/deleted 筛选不混入 ready 卡片，同 ID 旧 pending 响应不能覆盖完成结果，游标和其他记录保留。workspace 回归测试与 typecheck 通过，提交 `e9358e8`。
- [x] 4. 替代文本：完成失败后编辑中英文 alt，再重试确认，最新文本按完成素材 ID 保留，包括素材暂时被 pending 筛选隐藏的场景。组件回归测试通过，提交 `5f1fa1e`。
- [x] 5. 滚动升级地址：`EnsureAssetSourceURL` 仅原子补全缺失地址并返回首次胜出的 URL，不修改状态或 metadata。列表只修复返回页；已持久化 URL 不重新解析，解析或存储失败不返回部分列表。服务、仓储及真实 PostgreSQL 并发测试通过，提交 `4dc546c`。
- [x] 6. 分页性能：迁移 `0005_asset_list_indexes.sql` 添加单状态复合索引和默认未删除列表的部分索引；查询消除可空游标 OR，默认谓词匹配部分索引。真实 PostgreSQL 100,000 条数据、四种筛选的首/深页共八个查询计划通过，提交 `22f59ec`。
- [x] 7. 复审与门禁：独立复审发现并修复列表地址补全与事务读后写的关联竞争，事务内 GetAsset 加行锁，普通读取保持无锁。真实数据库覆盖 pending/ready 到 ready/deleted 的四种转换，提交 `36135fb`。补修后复审没有遗留阻断问题，完整门禁和覆盖率通过。

## 验收边界

所有行为测试必须先捕获原缺陷。上传使用真实网络连接，不以直接 Handler 调用代替期限验证。已有素材 URL 不因当前提供商配置而漂移。正式云账号的 OIDC、COS 和 EdgeOne 集成仍需要独立冒烟，本任务不部署。

## 验证结果

本次修复均先由失败行为测试捕获，再运行最小回归与受影响套件。滚动升级的启动迁移原本已回填旧记录；实际缺口是迁移后旧实例继续写入 NULL，因此保留 nullable 字段与旧二进制兼容，改为读取时原子补全。

最终代码验证：

- `pnpm verify`：退出码 0，lint、typecheck、Schema 19 项、管理端 75 项、公开站 82 项和脚本 21 项测试通过；两站静态生成及公开站产物检查通过。
- `pnpm verify:go`：退出码 0，gofmt、生成副本、全包测试及 vet 通过，包含真实 PostgreSQL 集成测试。
- `pnpm test:coverage`：退出码 0，Schema、管理端和公开站覆盖率门禁通过，语句覆盖率分别为 90.47%、88.70% 和 87.43%。
- `pnpm test:coverage:go`：退出码 0，全包加权语句覆盖率 83.29%，超过 80% 门槛，包含补修后的数据库测试。
- 真实 PostgreSQL 测试在独立 Schema 内执行两次迁移、并发地址补全、事务行锁竞争和 `EXPLAIN (ANALYZE, BUFFERS)`；分页计划没有全表扫描或排序，扫描行数保持有界。测试结束后删除各自 Schema，不访问现有应用表。
- 独立复审重新运行两个管理端回归文件共 18 项测试和五个受影响 Go 包测试，全部通过。

验证边界：Go race detector 因当前环境未启用 CGO 而未运行，不能视为通过。真实 OIDC、COS 和 EdgeOne 云集成、部署冒烟未执行。新增索引首次构建会暂时阻塞素材写入，维护窗口要求已记录在服务 README；本地查询计划结果不代表生产延迟指标。
